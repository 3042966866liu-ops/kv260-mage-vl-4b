# M332: 局部解析器提速未转化为固定视频收益

这是**未晋级的实验候选**，不是默认部署代码。目标是在不改变模型、Prompt、权重、T32 核或输出数值的条件下，把 M236 输出解析器的 FP32 `ldexp` 缩放改为精确 2 的幂原位乘法。

离线实函数检查覆盖三种宽度、shift 0–6 和 1/31/32 个有效 Token，共 63 个完整输出组合，逐字节一致。KV260 A53 合成解析器短测每形状 15 对交错样本，q/gate/down 的中位数局部比值分别为 2.0345×、1.7561×、2.0372×；[原始微测 JSON](MICRO_BOARD_RESULT.json)不代表完整视频收益。

同输入固定视频 A/B 的两次语义推理均通过。四帧张量哈希相同、159 Token、相同输出 `0`/Token 15/ABSENT、稳定 Build `0x4D395832`、各 778 次语言逻辑 FPGA 调用。候选实际导入了[隔离包](board_package/)中的 M236 文件，而非稳定版。结果：

| 加载外指标 | 稳定基线 | M332 候选 |
| --- | ---: | ---: |
| 首 Token | 205.050 s | 225.274 s |
| 视觉 | 44.142 s | 43.873 s |
| 语言 Prefill 至首 Token | 160.831 s | 181.326 s |

预登记端到端门槛为至少节省 11.536 秒（M328 230.721 秒的 5%）且超过波动。本轮候选反而多用 20.224 秒，因此判为 **`FAIL_E2E_GAIN`，不替换稳定部署**。完整机器记录：[稳定基线](BASELINE_BOARD_RESULT.json)、[候选](CANDIDATE_BOARD_RESULT.json)、[复算摘要](SUMMARY.json)。这是一对视频，不足以确定差距是否可重复；相同的一个 Token 和二元分数也不等于完整 logits 逐元素验证。加载前段另为 91.310/135.371 秒，不混入首 Token。

第一次候选尝试在加载 FPGA 前被 release-only 路径白名单拒绝。版本化 v2 包只精确放行自身候选目录，先通过 pre-overlay 导入闭包，再运行完整视频；该封装失败未被改写成模型失败。原始 COM3 日志保存在维护者工作区，未随仓库提交。包与结果不含模型权重、bitstream 或视频帧，因此**不能直接从本仓库重新上板**；需要另行取得合法匹配资产并通过同终端环境/包哈希门禁。稳定回滚未改。

无需板卡可复查解析器数值：

```bash
python3 scripts/optimization/m332_verify_runtime_parser.py
```

此实验说明局部函数微测不能替代端到端证据。下一优化必须先对真实视频 Prefill 的权重读取、解析、设备等待与 PS 工作做同条件分段，再只改主导成本。
