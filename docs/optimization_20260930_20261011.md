## M443 实现

新核为四 pair、64 连续输入、II=1、深度 34，保持原 FP32 顺序。[冻结 C++ 源](../tmp/m443_pair_pipeline_03/hls/mage_prefill_m89x_runtime/mage_prefill_m89x_runtime.cpp) SHA-256 为 `4da9eadbe97d8b8b072e109ab44c155e5f45d715fff87b4f972a1ff538421040`。

本地原工程已完成资源 guard、完整 417792 输出 CSim、新 DUT/VIP 六项 RTL、4.8 ns 核 OOC 和独立 200/100 MHz 全壳。RTL 的 legacy M441 schema 标签不改变实际 M443 Build 与六个新 case，不能称复用 M441 仿真。

核心 OOC 实际 4.690 ns，WNS +0.110 ns、WHS +0.033 ns。全壳 WNS +0.0424238406 ns、WHS +0.0096276319 ns、WPWS +1.0 ns；LUT 51573、FF 62964、BRAM tile 82、URAM 64、DSP 1184。旧严格 collector-03 FAIL 保留在本地；04 仅凭本次精确 log/DCP 与独立只读 checkpoint 验证另立闭合，未证明启动错误根因。

新 bit SHA-256 `555ae52842ae901c863152a5a02b2dd4583ed95691255d98889a25ae579c27ae`；M441 对照 bit `73350f615a5bc98d1d8aa2b5c69c4d6fd399aa1ef651f37411cbed21c0daed2e`。新 bit 的实际同 PID/PFN 1904 页配置释放合同独立验证，未修改旧 CMA 白名单；随后按 Build ID、descriptor、chain、单层、固定文本、159 视频和完整请求逐级完成。
