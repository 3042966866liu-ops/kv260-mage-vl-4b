The M325 three-step totals correspond to approximately 0.027539 and 0.027222 *forced diagnostic* tokens/s, respectively. The second token is EOS, so these are not user-visible sustained chat throughput. Cache state was not randomized or proven equivalent across the paired runs; do not use this single pair for a causal speedup claim. Initialization, pre-reading, instrumentation and cold/hot cache costs must be quoted separately when measured. M324 KV852 three-step Decode was a different session and is not concatenated with M277 TTFT. M328 generates only one token and has no sustained Decode result. Its direct sample does not validate Web alarm triggering, four-frame temporal understanding, calibrated safety accuracy or real-time performance. The 4B slow review is minutes-scale even while the fast Web safety channel can continue receiving frames.
