# v0.1.0 research preview — proposed release notes

Stable default: M254 dual-path Web service using M120 T32 language Build `0x4D395832`; visual tower and control operators on PS. The v7 archive passed an independent owner-KV260 install with fixed-text E2E and no-frame Web runtime-ready. A separate M328 companion then passed direct fixed-video 4B E2E on that installed tree. This is not an alarm-triggered Web video gate or a generic clean-OS provisioning test. BACT-V2 frozen selector, 27-point historical board-cost evidence and 12-clip retrospective quality recomputation can run without weights. OP01 Decode-one code is experimental and not a stable alternative.

The source tree excludes weights, tokenizer binary JSON, detector checkpoint and bitstream. GitHub Releases provides the v7 prebuilt TAR as eight 500 MB parts, the M328 video companion and an eight-part `RELEASE_PARTS.json`; the [repository copy](../../manifests/release_parts_v7.json) records the same split. The Release manifest has been downloaded and checked, while a complete download/reassembly and hash check of the public archive parts has not been recorded. The exact stable M125 language/LM Head manifests and eight shards were located and rehashed on the owner's WSL host, but remain external to Git; see [asset provenance](../stable_asset_provenance.md) and [external asset map](../../manifests/external_assets.json). M328 direct-video first Token was 230.721 s excluding initialization; M325 same-session stable fixed-video TTFT was 228.531 s in a different run. One OP01 pairing did not show a full-session benefit. The capacity FIFO long test for OP01 was stopped, not passed. See [results](../results.md) and [limitations](../limitations.md).

Release status: **eight-part asset set and matching manifest published; public archive reassembly not yet recorded**. Do not present the current attachment set as a fully verified installer. File-level third-party redistribution and attribution remain open despite the upload. The owner approved the AI-generated sample frames, not the third-party components inside the base archive. A generic clean-OS installation test is still required before claiming that scope. The owner-board independent first install is evidenced, but full-shell source rebuild is NOT_RUN.
