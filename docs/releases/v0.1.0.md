# v0.1.0 research preview — proposed release notes

Stable default: M254 dual-path Web service using M120 T32 language Build `0x4D395832`; visual tower and control operators on PS. The v7 archive passed an independent owner-KV260 install with fixed-text E2E and no-frame Web runtime-ready. A separate M328 companion then passed direct fixed-video 4B E2E on that installed tree. This is not an alarm-triggered Web video gate or a generic clean-OS provisioning test. BACT-V2 frozen selector, 27-point historical board-cost evidence and 12-clip retrospective quality recomputation can run without weights. OP01 Decode-one code is experimental and not a stable alternative.

The source tree excludes weights, tokenizer binary JSON, detector checkpoint and bitstream. The v7 prebuilt TAR and M328 video companion are locally hash-locked but have no public download URL. The exact stable M125 language/LM Head manifests and eight shards were located and rehashed on the owner's WSL host, but remain external; see [asset provenance](../stable_asset_provenance.md) and [external asset map](../../manifests/external_assets.json). M328 direct-video first Token was 230.721 s excluding initialization; M325 same-session stable fixed-video TTFT was 228.531 s in a different run. One OP01 pairing did not show a full-session benefit. The capacity FIFO long test for OP01 was stopped, not passed. See [results](../results.md) and [limitations](../limitations.md).

Release status: **draft / not uploaded**. Before public publication, clear project and upstream-code licensing, confirm sample-video redistribution rights, supply a lawful asset download route, and make a generic clean-OS installation test if claiming that scope.
