# v0.1.0 研究预览——发布说明草案

稳定默认入口为 M254 双通道 Web 服务，使用 M120 T32 语言 Build `0x4D395832`；视觉塔和控制算子在 PS 执行。v7 归档已在所有者 KV260 独立目录完成固定文本 E2E 和无帧 Web 运行时就绪验证，随后单独的 M328 伴随包在该安装中通过直接固定视频 4B E2E。这不是自动报警 Web 视频验证，也不是通用干净系统配置测试。BACT-V2 固定选择器、27 点历史板端成本证据和 12 段视频历史质量复算无需权重即可运行。OP01 Decode-one 是实验代码，不是稳定替代版本。

源码目录不含权重、tokenizer 二进制 JSON、检测器 checkpoint 或 bitstream。GitHub Releases 已提供 v7 TAR 的八个分片（前七个各 500 MB）、M328 视频伴随包和八分片 `RELEASE_PARTS.json`；[仓库副本](../../manifests/release_parts_v7.json)记录相同拆分。Release 清单已下载并核对；公开归档分片的完整下载、重组和哈希检查尚无记录。精确稳定 M125 语言／LM Head 清单及八个分片已在所有者 WSL 主机定位并重算哈希，但不进入 Git，见[资产来源核验](../stable_asset_provenance.md)和[外部资产清单](../../manifests/external_assets.json)。M328 直接视频首 Token 为 230.721 s（不含初始化）；另一轮 M325 同会话稳定固定视频 TTFT 为 228.531 s。一次 OP01 配对没有显示完整会话收益，OP01 容量 FIFO 长测是已中止而非通过。条件见[结果](../results.md)与[限制](../limitations.md)。
