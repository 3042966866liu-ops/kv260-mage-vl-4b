# Hardware build scope

Stable source is in [T32 HLS](../hls/mage_prefill_m89x_runtime/) and historical host/runtime contracts in `deployment/mage_vl4b/m175_m120_fixed_text_candidate/`. The HLS directory contains C++ headers, CSim/CoSim testbenches and Tcl, including `run_m134_export_m120_m89x2.tcl`. Recursive quoted-include source closure is copied through `mage_prefill_m89s/m89d/m89o/m89n/m89h/m89e` and related sibling modules; `python3 scripts/audit_hls_includes.py` reports `missing=0` in this snapshot. This is not a compiler check. An HLS `export_design` generates an IP, **not** a KV260 bitstream.

The HLS Tcl targets `xck26-sfvc784-2LV-c`; strict tests use 4.8 ns plus 1.3 ns uncertainty. The historically executed full-shell artifact is Build `0x4D395832`, kernel `mage_m120_m89x2_0`, `m120_m89x2_t32.bit/.hwh`. The M300 binding reports KV260 routed LUT 39,613/117,120 (33.82%), FF 46,882/234,240 (20.01%), BRAM 70/144 (48.61%), URAM 16/64 (25.00%), DSP 1,070/1,248 (85.74%), WNS +0.147 ns and WHS +0.010 ns. These are **historical source-project measurements**, not a fresh rebuild from this snapshot. The copied M134 export Tcl hard-codes the old Windows workspace and `m132_m120_fifo_backpressure_hls` project; it is kept as provenance and cannot be used as a clean-release build command.

This release does not include a verified clean, relocatable Vivado system assembly: BD/IP wiring, PS/DDR/DMA/AXI maps, clocks/XDC, board part, full implementation and package script were not shown to close from a clean release checkout. Some project files in the parent workspace belong to other Qwen experiments and must not be silently treated as Mage-VL T32 design sources. `SOURCE_BUILD_VERIFIED=NOT_RUN`. We did not run CSim, CoSim, IP export, synthesis, route or overlay packaging for this release. Do not cite prior CSim/RTL passes as proof that the release snapshot rebuilds.

The OP01 Decode-one HLS source is in [experimental HLS](../hls/mage_decode_op01_one/); its stopped FIFO capacity long test remains stopped, and it must not replace the stable T32 bitstream by default.
