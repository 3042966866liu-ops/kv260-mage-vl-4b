# 校园安防视频演示

本地入口：`http://127.0.0.1:8766/`。双击同目录 `启动演示.cmd`。

## 演示操作

1. 板卡开机，在 COM3 进入 `root@kria`，关闭终端释放端口。不要让串口终端与工作器同时占用 COM3。
2. 启动演示。等待界面显示板卡就绪；工作器先加载模型并完成一次实际预热，预热答案不会进入演示界面。
3. 选择或拖入视频。实际输入画面先准备到板端，准备好后视频播放，`play` 事件提交一个新推理任务。
4. 实际返回 Yes：显示大红色警告和红色画面边框，暂停到本次采样位置。实际返回 No：不显示判断、提示条或报警记录。界面不显示 TTFT。
5. “重新演示”会重新播放并发起新任务；暂停后继续播放不会重复提交。替换视频会清空当前报警。识别失败显示中性连接问题，不作为“无刀具”。

## 输入与结果的真实范围

每次播放针对一张明确的代表画面做双视图推理，不是整段视频逐帧扫描。页面显示实际送入模型的缩略图和源时间。推理期间短视频循环播放，报警只由新结果触发，不使用计时器。

当前两个已验收素材按视频 SHA 固定提取画面：校园走廊灰衣人物视频（3）第 2 秒、校园操场视频（12）第 0 秒。绑定文件只有输入路径与哈希，没有答案；每次播放仍实际运行模型。其他视频由浏览器提取时长约 25% 处的中心画面；未承诺任意新视频的准确率。文件名、旧结果和人工标签均不能生成本次答案。

每个结果绑定独立任务 UUID、工作器会话、输入像素 SHA、部署清单与完整词表 logits SHA。先保存并同步真实板端证据，再通知网页。CPU／浏览器界面测试结果明确标注为软件样例，不作为 FPGA 验收。
